# Свой домен (задача 2.1)

## Какой

**Рекомендация: `buildpodmatch.ru`** — совпадает с названием сайта «Билд под матч»: на стриме говорится
«билд под матч точка ру», и человек сразу пишет правильно. Проверка 16.11.2026 (по DNS) — похоже, свободен;
точно скажет регистратор при покупке.

Запасные (тоже похоже свободны): `matchbuild.ru`, `dlbuild.ru`, `buildpodmatch.com`.
Занят: `podmatch.ru`. Не берём имена с `lock` (`lockbuild.ru`, `buildlock.ru`) — похожи на чужие сайты
(lockbuilds.com, deadlocked.gg), люди будут путать.

## Где купить

Цена .ru — 200–900 ₽ за первый год (продление обычно чуть дороже — смотреть цену продления).

1. **reg.ru** или **nic.ru** — крупные российские регистраторы. Администратор домена — физлицо, нужны ФИО и паспорт
   (гражданство Беларуси подходит).
2. Если российский регистратор не примет белорусскую карту — **hoster.by** (белорусский регистратор, тоже регистрирует
   .ru) или другой, где удобно платить.

При покупке **не нужны**: хостинг, конструктор сайтов, почта, SSL-сертификат (HTTPS бесплатно даст GitHub),
«защита персональных данных» за отдельные деньги (данные физлиц в .ru и так скрыты). Только сам домен.

## Что прописать у регистратора (раздел «DNS» / «Управление зоной»)

Если регистратор предлагает «парковку» или свои записи — удалить их и добавить:

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `naivgot.github.io.` |

(Это адреса серверов GitHub Pages — сайт остаётся на том же бесплатном хостинге.)

Записи начинают работать от 15 минут до суток.

## Что сделать на GitHub

1. Репозиторий `deadlock-build-advisor` → **Settings → Pages → Custom domain** → вписать `buildpodmatch.ru` → Save.
2. Когда GitHub проверит домен (галочка) — включить **Enforce HTTPS** (сертификат выдаётся сам, до суток).

## Что сделаю я (≈ 30 минут после покупки)

- Адрес сайта в коде (`SITE_URL`): карта сайта, превью для соцсетей, canonical — на новый домен.
- `robots.txt` начнёт работать сам (он в корне домена).
- Яндекс Вебмастер: добавить новый сайт, подтвердить (файл в корне), «Переезд сайта» со старого адреса.
- Метрика: новый адрес в настройках счётчика (счётчик тот же, номер не меняется).
- Старый адрес `naivgot.github.io/deadlock-build-advisor/` GitHub сам перенаправит на новый домен —
  старые ссылки и иконки на телефонах не сломаются.
- Проверю, что всё открывается по `https://buildpodmatch.ru` и с `www`.
