# Проверка логики на реальных матчах (задача Д6)

Скрипт: `scripts/backtest.js`. Запуск: `node scripts/backtest.js --fetch` (скачать матчи, 1 SQL-запрос),
потом `node scripts/backtest.js` (посчитать; около 5 минут). Нужен собранный сайт (`npm run build:site`).

## Как считаем

- Матчи — только сыгранные **после** даты нашей статистики (иначе логика проверяет сама себя).
- Берём матчи целиком (все 12 игроков) и для каждого игрока строим совет под его настоящий состав:
  враги на его линии, остальные враги, напарник, союзники.
- Победители богаче и покупают больше предметов, поэтому «совпадений с советом» у них больше просто так.
  Сравниваем только **внутри слоя**: тот же герой и похожее число покупок (по 3 предмета). Разницы слоёв
  усредняем с весами (как в методе Мантеля — Хензеля).
- Главный вопрос — что дают **отличия** совета от простого «купи самое популярное».

## Результат 16.11.2026 (6 399 матчей, 76 788 игроков, после 15.11)

| Что сравниваем (купившие − не купившие) | Разница побед |
|---|---|
| 1. Покупки ближе к нашему совету | **+2,6%** |
| 2. Покупки ближе к «просто популярному» | +0,3% |
| 3. Купил наш «особый» предмет (нет в популярном) | **+3,0%** |
| 4. Купил популярный предмет, который мы убрали | −0,5% |
| 5. Купил что-то из «Ситуативных» — до правки | **−3,8%** |
| 5. То же — после правки | −0,6% |
| 6. Купил контру из основного пути | −0,3% |

## Выводы

- Совет связан с победами заметно сильнее, чем «просто популярное» (1 против 2) — логика добавляет пользу.
- Наши отличия от популярного работают в плюс (3), убранное нами — не лучше (4).
- Контры в основном пути безвредны (6).
- «Ситуативные» были в минусе: раздел сортировался только по ручному справочнику контр и тянул предметы,
  с которыми герой и в среднем побеждает реже. **Правка:** сортировка по полной оценке (контра + статистика),
  контры с подъёмом хуже −1,5% не показываем, если статистика против именно этих врагов не говорит обратного
  (`situationalMinLift`). После правки — около нуля.

## Чего эта проверка не умеет

- Связь ≠ причина. Защитные предметы часто покупают, когда уже проигрывают, — поэтому у них «минус» даже
  если предмет хороший. Точнее — только сравнение по времени покупки (этап 3, бэктест на своей базе матчей).
- Статистика предметов посчитана за весь патч, а проверочные матчи — его последние дни: проверка «почти честная».
- Повторять после больших изменений логики или нового патча.
