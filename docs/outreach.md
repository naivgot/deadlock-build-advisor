## Как сделать ссылку с меткой

У каждого блогера и канала — своя ссылка, чтобы в Метрике было видно, сколько людей он привёл.

```
npm run link -- --source=yt_ivan --medium=video --campaign=wave1
```

С готовым билдом (например, на героя блогера против его неудобного врага):

```
npm run link -- --source=yt_ivan --medium=video --campaign=wave1 --hero=Haze --lane=Abrams,Kelvin --enemies=Dynamo,Seven
```

Схема меток — пишем латиницей, без пробелов:

| Метка | Что значит | Примеры |
|---|---|---|
| `source` | кто привёл: площадка + имя | `yt_ivan`, `tw_ivan`, `tg_deadlockru`, `vk_deadlock`, `dtf_post`, `steam_guide` |
| `medium` | где именно | `video`, `stream`, `post`, `chat`, `description` |
| `campaign` | волна | `wave1` (мягкий запуск), `wave2`, `patch_2026_12` |

Префиксы площадок: `yt` — YouTube, `tw` — Twitch, `tg` — Telegram, `vk` — VK, `ds` — Discord, `dtf`, `pikabu`, `steam`.

**Где смотреть:** Метрика → Отчёты → Источники → «Метки UTM». Там видно визиты по каждой метке и цели
«Собрал билд», «Поделился билдом». Главная цифра — сколько людей **собрали билд**, а не просто зашли.

Пересланные ссылки сайт метит сам: `share` (кнопка «Поделиться»), `tg_share` (кнопка «В Telegram»).
